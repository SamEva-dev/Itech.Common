# PedagoraPilot.Security.Contracts

Shared authorization contract for **Pedagora Pilot**.

- Application code: `pedagora-pilot`
- Stable permission codes shared by AuthGate, Pedagora Pilot APIs and the Angular UI.
- Role defaults are bootstrap defaults; business-scope membership rules remain owned by Pedagora Pilot.

Do not rename released permission values. Add new permissions when the authorization model evolves.
